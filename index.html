Mengenal Bahasa Pemrogaraman

Bahasa pemrograman digunakan untuk memberikan instruksi kepada komputer. Setiap bahasa mempunyai karakteristik dan kegunanaan yang berbeda.

Seseorang programer sebaiknya memahami konsep pemrograman, bukan hanya menghafal sintaks.

Contoh Bahasa Pemrograman

  1. Python
  2. Java
  3. JavaScript
  4. PHP
  5. C++
  6. Dart

Istilah Bahasa Pemrogaraman

  • Syntax
      • Aturan penulisan kode dalam sebuah bahasa pemrograman
  • Variable
      • Tempat untuk menyimpan sebuah nilai atau data
  • Function
      • Kumpulan instruksi yang dapat dipanggil untuk melakukan tugas tertentu
  • Library
      • Kumpulan kode yang dapat digunakan kembali dalam program
